# Security policy

## Supported versions

Security fixes target the latest tagged release. Please check whether an issue still occurs on that release before reporting it.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository's **Security** tab when it is available. Include the affected version, impact, and steps to reproduce. If private reporting is unavailable, contact the maintainer through a private channel rather than opening a public issue.

Do not disclose exploit details, API keys, webhook secrets, or customer data in a public issue or pull request. The maintainers will coordinate a fix and disclosure with the reporter.
